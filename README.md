# 萌宠连连看

一款可在浏览器（含手机）游玩的**萌宠主题连连看**小游戏。

## 在线游玩

在线地址：https://cryptotumor9527.github.io/pet-lianliankan/

打开上面的 GitHub Pages 地址即可游玩。手机建议「添加到主屏幕」全屏横屏游玩；部分安卓浏览器会在开始游戏时自动请求横屏。

## 怎么玩

1. 点击「开始游戏」。
2. 点选两只**相同**的小动物；若能用不超过 **2 次转弯**的路径相连（可绕出棋盘外一圈），即可消除。
3. 限时内清空棋盘过关。每次消除会少量回填时间；时间耗尽则游戏结束。
4. 「提示」高亮一对可消；「重排」或无解时会消耗「生命」并重新打乱剩余格子。
5. 共九关，后期会出现上下分离、左右分离、对齐、重力等滑块规则。

## 本地打开

直接用浏览器打开仓库根目录的 `index.html` 即可（无需构建）。
